# japanese-learning

Japanese Learning Resource 收集的日语学习资源.

## AI工具

[Chatgpt](AI/Chatgpt.md): 学语法练口语都可以.

[豆包](AI/豆包.md): 无需翻墙,但是只能问问单词,语法,不支持日语对话.

[Gemini](AI/Gemini.md): 可以用日语对话,但是不可以说中文😭.你如果英语好的话,可以同时学两门外语.

[Cici](AI/Cici.md): 豆包的海外版,支持日语对话.


## AI学习工具
我们真的赶上好时候了,有这么多工具来帮助我们学习,就算学不会过两年算力成本降下来估计实时翻译的耳机和眼镜也出来了😄.

介绍的这两个都是浏览器插件,会根据你的语言水平自动选择网页上的部分母语词汇翻译成想要学习的语言词汇,鼠标悬停的时候会显示解释,还能发音.

但是没一个能收藏和导出的,这不学完就忘吗.要是能收藏词汇所在句子导出到anki就完美了.

而且他没办法知道你哪个词会哪个词不会,有时候你会的词给你翻译了,不会的词不翻译,这就很尴尬.还是我说的,没有单词本,能把欧路查的词导入进来就好了.

[Ries](AI/Ries.md): 闭源,得用他们的翻译服务,不能使用自己的api key,不支持懒加载(一个网页很长,翻到了再翻译,这样积分消耗比较少,性能也好),所以免费版的高强度刷网页不够用,支持视频(需要有字幕的,比如youtube能开cc字幕的,内嵌的不可以).

[illa-helper](AI/illa.md): 免费的,但是需要你有自己的大模型api key,网上大善人很多,阿里,字节,groq都有免费额度,linux.do也有好多免费送的,开源.

[日本語文章解析器](AI/analyse.md): 自学日语的应该都有过那种痛. 唉?这不对啊,老师不是说这里应该用が吗?为什么这里是を?这个工具可以帮你分析句子结构,每个词汇的成分,在句子中的作用.

[CallAnnie](AI/CallAnnie.md): 专门用AI学习语言的APP,有免费的基础版和收费订阅.(最近一直连接失败)
